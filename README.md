# Hi, I'm Simon 👋

I'm a Senior Fullstack Engineer from Dortmund, Germany.

I like building software that feels good to use and is still nice to work on months later. That usually means clean interfaces, solid architecture, useful tooling, and enough care for the little details.

I spend most of my time somewhere between frontend, backend, product thinking, and design. Lately, I'm also exploring the world of AI: agentic workflows, AI-powered applications, automation, and new ways software can help people get things done.

Away from the keyboard, I like hiking 🥾, traveling 🌍, seeing more of the world ✈️, and spending time with my Golden Retriever 🐕.

## Current Project

I'm currently building [Envoy Mail](https://envoymail.de), a modern cross-platform email client focused on making email feel calmer, faster, and easier to manage.

The project brings together Flutter, thoughtful UI, local-first product thinking, secure device integrations, and a clean experience across platforms. If you care about better email workflows, keep an eye on it.
